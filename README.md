# IRGETAS

ИИ-помощник частного застройщика в Алматы: выбор технологии (газоблок, кирпич, каркас), смета с источниками цен, план действий, PDF-отчёт.

Команда **ZhB Team**, группа РПЗС-25-8. Экзаменационный проект по «Основам ИИ».

## Стек
- Python, Streamlit: сайт
- Языковая модель через API: извлечение параметров, подбор и объяснение
- pandas + CSV/Excel: база цен и норм
- ReportLab: PDF-отчёт
- Хостинг: Streamlit Community Cloud
- API-ключи только в Secrets, не в коде

## Структура
- `app.py`: приложение (сейчас пустая форма)
- `prompts/`: версии промптов
- `data/`: база цен и характеристик технологий
- `.streamlit/secrets.toml.example`: пример файла с ключом

## Запуск
```bash
pip install -r requirements.txt
streamlit run app.py
```
